# Épico B-7 — Capturar alternate_link dos assignments

## Objetivo

Guardar o link da tarefa no Google Classroom (`alternateLink`, devolvido pela API em cada
`courseWork`) para o frontend oferecer um "Abrir no Classroom" (consumido em F-11). Hoje o campo
não é capturado nem armazenado.

## Mudanças

```
1. Migration: add_column :assignments, :alternate_link, :string, limit: 1024 (nullable)
2. Sync (assignments_controller#assignment_attributes): capturar course_work["alternateLink"]
3. Serializers: expor `alternate_link` no JSON do dashboard e nas demais listagens de assignment
```

## Critérios de aceitação (specs obrigatórios)

1. A migration adiciona a coluna `alternate_link` (string, nullable) em `assignments`
2. `POST /assignments/sync` salva o `alternateLink` vindo do `courseWork`
3. Re-sync atualiza o `alternate_link` de assignment existente
4. `courseWork` sem `alternateLink` → `alternate_link` fica `nil` (não quebra o sync)
5. O JSON do `GET /dashboard` passa a incluir `alternate_link`

---

## Considerações especiais

- A coluna é **nullable**: dados sincronizados antes deste épico ficam com `alternate_link` null até
  o próximo sync. O frontend (F-11) esconde o botão quando o link é null.
- Não é escopo guardar o `alternateLink` do **curso** (só do assignment) — feature pedida é a nível
  de tarefa.
- Os endpoints de listagem por curso e de detalhe (B-9) devem incluir `alternate_link` no serializer
  deles também; este épico garante o campo no dashboard e na captura do sync.
