# Épico B-2 — POST /assignments/sync (+ C-2: auto_priority)

## Spec do endpoint

```
POST /assignments/sync
Auth: Bearer <jwt> obrigatório
Lógica:
  1. Para cada Course do current_user:
     - GET https://classroom.googleapis.com/v1/courses/:google_course_id/courseWork
       com Authorization: Bearer <current_user.google_access_token>
     - Upsert assignments via google_assignment_id (find_or_initialize_by)
     - Calcular auto_priority por prazo (ver C-2 abaixo)
  2. Todo o upsert em uma única transaction
Response 200: { "synced": Integer }
Response 401: { "error": "unauthorized" } (sem token JWT)
Response 502: { "error": "classroom_api_error", "message": String } (falha na API Google)
```

### C-2: Cálculo de auto_priority por prazo

Implementar como método de classe em `Assignment`:

```ruby
def self.calculate_auto_priority(due_date)
  return nil if due_date.nil?
  days_until_due = (due_date.to_date - Time.zone.today).to_i
  [days_until_due, 1].max   # mínimo 1, sem limite superior
end
```

Esse método é chamado durante o sync para cada assignment com `due_date` presente.

## Critérios de aceitação (specs obrigatórios)

1. `POST /assignments/sync` com token válido → chama API Google para cada course → upsert → 200 com count
2. Re-sync não duplica assignments (idempotente via `google_assignment_id`)
3. Re-sync atualiza `title` e `due_date` de assignment existente
4. `auto_priority` calculado para assignments com `due_date`
5. `auto_priority` nil para assignments sem `due_date`
6. Falha na API Google (status != 200) → 502 com `classroom_api_error`
7. Sem token → 401

## Considerações especiais

- **B-4 (token refresh) não está implementado ainda.** Se o `google_access_token` retornar 401 da API Google, retorne 502 com `classroom_api_error` por ora. B-4 tratará o refresh depois.
- **Campos da API Google** (`courseWork`): `id` → `google_assignment_id`, `title`, `description`, `dueDate` (objeto com `year`, `month`, `day`) → `due_date`, `workType` ignorado, `state` mapeado diretamente
- **`dueDate` da API Google** é um objeto `{ year:, month:, day: }` — construir `Date.new(year, month, day)` antes de salvar
- **`state` da API Google** pode ser `"PUBLISHED"` (mapear para `"CREATED"`) ou outros valores de `VALID_STATES`
- Usar `find_or_initialize_by(google_assignment_id:, user: current_user, course:)` para o upsert
