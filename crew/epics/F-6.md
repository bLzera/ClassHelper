# Épico F-6 — Editar prioridade manual (frontend)

> **Épico de FRONTEND.** Gate = `run-fe-tests.sh` + `run-fe-lint.sh` (ver F-2). Depende de **F-4**.

## Objetivo

Permitir que o usuário defina/altere a `manual_priority` de uma tarefa direto no dashboard, refletindo
a mudança na lista. A `manual_priority` tem precedência sobre a `auto_priority` (menor número = maior
prioridade).

## Contrato da API consumida

```
PATCH /assignments/:id/priority   (Bearer)
  Body: { manual_priority: Integer }
  200: assignment atualizado (mesmos campos do dashboard)
  404: { error: "not_found" }
```

## Critérios de aceitação (specs obrigatórios)

1. Cada `AssignmentCard` expõe um controle pra editar `manual_priority`; salvar chama
   `PATCH /assignments/:id/priority` com `{ manual_priority: <int> }` (mockar o axios/api)
2. Validação no client: só aceita inteiro positivo; valor inválido não dispara a request e mostra feedback
3. Em **sucesso**, o item correspondente na lista do store é atualizado com a `manual_priority` nova
   (sem refazer o GET /dashboard inteiro)
4. Reordenação: como `manual_priority` tem precedência, a lista reflete a nova ordem por prioridade
   efetiva após a edição (reordenar no client OU refazer o fetch — documentar a escolha)
5. `404` da API → feedback de erro, sem quebrar a tela
6. Store `assignments`: `updatePriority(id, value)` atualiza o item certo e trata erro

## Considerações especiais

- **Reordenação:** decidir entre reordenar localmente pela prioridade efetiva
  (`manual_priority ?? auto_priority`, asc, nulls last — espelhando o backend) ou simplesmente chamar
  `fetchDashboard` de novo após o PATCH. A primeira é mais responsiva; a segunda é mais simples e
  garante consistência com o backend. Documentar no output.
- Update otimista é opcional — se usar, reverter em caso de erro.
- Não dá pra "limpar" a prioridade manual pelo contrato atual (só setar Integer); se isso for desejável,
  é um épico de backend separado — fora do escopo aqui.
- Tailwind; manter o editor pequeno e testável isoladamente.
