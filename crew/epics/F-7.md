# Épico F-7 — App shell modular (layout + sidebar + sessão)

> **Épico de FRONTEND.** Gate = `run-fe-tests.sh` + `run-fe-lint.sh`. Base para F-8..F-11.

## Objetivo

Trocar o `App.vue` "só `<RouterView/>`" por um **shell** com **sidebar fixa** à esquerda e área de
conteúdo no centro-direito (via rotas aninhadas). Inclui a "revisão geral" estrutural do frontend:
o `DashboardView` deixa de carregar header/sync/logout inline — isso migra pro shell. **Desktop-first**
(responsividade fica para uma sprint futura).

## Layout

```
┌────────────┬──────────────────────────────┐
│  SIDEBAR   │                              │
│  ClassHelper                              │
│  • Todas as tarefas   │   <RouterView />  │  ← conteúdo da rota ativa
│  • Cursos             │   (centro-direito)│
│  [Sincronizar agora]  │                  │
│  última sync: há Xmin │                  │
│  ──────────           │                  │
│  Fulano (email)       │                  │
│  [Sair]               │                  │
└────────────┴──────────────────────────────┘
```

- Itens de navegação: **Todas as tarefas** (`/` → dashboard global) e **Cursos** (`/courses`).
- Bloco de **sessão** no rodapé: nome + email do usuário (de `auth.fetchMe`) e botão **Sair**.
- Placeholders nesta etapa: o botão **"Sincronizar agora"** e o indicador **"última sync"** ganham a
  lógica real em F-8 (aqui podem ser estáticos/desabilitados, mas já posicionados).
- Rotas autenticadas viram **filhas** de uma rota de layout; rotas públicas (login, callback) ficam fora.

## Critérios de aceitação (specs obrigatórios)

1. Rotas autenticadas renderizam dentro do `AppLayout` (sidebar visível + conteúdo da rota)
2. A sidebar mostra os links "Todas as tarefas" e "Cursos" e navega para eles
3. O bloco de sessão mostra nome/email do usuário (de `useAuthStore().user`); se ainda não carregado,
   dispara/usa `fetchMe`
4. O botão "Sair" chama `authStore.logout()` e redireciona para `/login`
5. Rotas públicas (`/login`, `/auth/callback`) **não** renderizam o shell
6. O link "ativo" da navegação recebe destaque visual (estado ativo do router-link)
