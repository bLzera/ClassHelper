# Épico F-9 — Lista de cursos + tela de curso

> **Épico de FRONTEND.** Gate = `run-fe-tests.sh` + `run-fe-lint.sh`. Depende de **F-7**, **B-6** e **B-9**.

## Objetivo

Adicionar a navegação por curso: uma **lista de cursos** (item "Cursos" da sidebar) e, ao selecionar
um, uma **tela do curso** com as tarefas dele ordenadas por prioridade (reusando o `AssignmentCard`).

## Contrato da API consumida

```
GET /courses                          (Bearer) → { courses: [ { id, name, section,
                                                   pending_count, next_due_date } ] }
GET /courses/:id/assignments?completed=<bool>  (Bearer) → { assignments: [ ... ] }
```

## Critérios de aceitação (specs obrigatórios)

1. A rota `/courses` lista os cursos do usuário (chama `GET /courses`); cada item mostra **nome**,
   **nº de tarefas pendentes** e **prazo da próxima** (quando houver)
2. Clicar num curso navega para `/courses/:id` (tela do curso)
3. `/courses/:id` lista as tarefas daquele curso ordenadas por prioridade efetiva, reusando `AssignmentCard`
   (chama `GET /courses/:id/assignments`)
4. Estados de **loading**, **erro** e **vazio** ("nenhuma tarefa neste curso") tratados em ambas as telas
5. Store `courses`: `fetchCourses()` e `fetchCourseAssignments(id, completed?)` gerenciam
   `loading`/`error` e os dados
6. Curso inexistente / 404 em `/courses/:id` → feedback de erro sem quebrar a tela
