# Épico C-2 — auto_priority por prazo

## Observação importante

**C-2 está integrado ao épico B-2.** O cálculo de `auto_priority` é executado durante o sync de assignments (`POST /assignments/sync`), então deve ser implementado junto com B-2.

Se B-2 já foi implementado, este épico consiste em:
1. Verificar que `calculate_auto_priority` existe em `Assignment` e está sendo chamado no sync
2. Adicionar specs específicos para o cálculo se não existirem

---

## Spec do cálculo

```ruby
# Em Assignment (método de classe)
def self.calculate_auto_priority(due_date)
  return nil if due_date.nil?
  days_until_due = (due_date.to_date - Date.today).to_i
  [days_until_due, 1].max   # mínimo 1; prazo passado → 1 (máxima prioridade)
end
```

Semântica: **menor número = maior prioridade**.

| Situação | auto_priority |
|---|---|
| Sem due_date | nil |
| Prazo hoje ou no passado | 1 |
| Prazo em 3 dias | 3 |
| Prazo em 30 dias | 30 |

## Critérios de aceitação (specs obrigatórios)

1. `Assignment.calculate_auto_priority(nil)` → nil
2. `Assignment.calculate_auto_priority(Date.today)` → 1
3. `Assignment.calculate_auto_priority(Date.today - 5)` → 1 (prazo passado, não negativo)
4. `Assignment.calculate_auto_priority(Date.today + 7)` → 7
5. `Assignment.calculate_auto_priority(Date.today + 30)` → 30

Specs em `spec/models/assignment_spec.rb` usando `spec_helper` (sem Rails helpers — não precisa de banco para testar método de classe com lógica pura).
