# Épico B-10 — POST /sync orquestrado com throttle (auto-sync)

> Depende de **B-6** (cursos) e **B-8** (submissões) — orquestra o sync completo num endpoint só.

## Objetivo

Um único endpoint que sincroniza **cursos + tarefas + submissões** de uma vez, com **throttle de 1h**
(não re-sincroniza se o último sync foi há menos de 1h), para o frontend disparar no login (F-8). O
botão manual "Sincronizar agora" pode **forçar** ignorando o throttle.

## Spec do endpoint

```
POST /sync?force=<true|false>     (Bearer)
Lógica:
  - se !force E last_synced_at presente E last_synced_at > 1h atrás:
      → não sincroniza; Response 200: { "skipped": true, "last_synced_at": ISO8601 }
  - senão:
      1. sincroniza cursos (igual /courses/sync)
      2. sincroniza tarefas de cada curso (igual /assignments/sync, já com submissões de B-8)
      3. user.update!(last_synced_at: Time.current)
      → Response 200: { "skipped": false, "synced_courses": Integer,
                        "synced_assignments": Integer, "last_synced_at": ISO8601 }
Response 401: { "error": "unauthorized" }
Response 401: { "error": "token_expired", ... }   (re-auth Google necessária)
Response 502: { "error": "classroom_api_error", ... }
```

Migration: `add_column :users, :last_synced_at, :datetime` (nullable).
Expor `last_synced_at` também no `GET /auth/me` (pro indicador "última sincronização" carregar já na entrada).

## Critérios de aceitação (specs obrigatórios)

1. `POST /sync` sem sync prévio → executa, atualiza `last_synced_at`, retorna contagens e `skipped: false`
2. `POST /sync` com `last_synced_at` há menos de 1h e sem `force` → `skipped: true`, **não** chama a API Google
3. `POST /sync?force=true` com sync recente → executa mesmo assim (ignora throttle)
4. `POST /sync` com `last_synced_at` há mais de 1h → executa normalmente
5. Orquestração: sincroniza cursos **antes** das tarefas; tarefas já gravam estado de submissão (B-8)
6. `GET /auth/me` passa a incluir `last_synced_at`
7. Erros propagados igual aos demais (`token_expired` → 401, `classroom_api_error` → 502)
8. Sem token → 401

## Considerações especiais

- **Não duplicar** a lógica de sync: extrair o upsert de cursos e o de tarefas+submissões para
  `ClassroomSyncService`, e fazer `courses#sync`/`assignments#sync` (os endpoints manuais existentes)
  e o novo `sync#create` chamarem o mesmo service. Documentar a refatoração no output.
- O throttle compara `last_synced_at` com `1.hour.ago`; o `force` (param manual) o ignora.
- Manter os endpoints `/courses/sync` e `/assignments/sync` existentes funcionando (não quebrar specs
  atuais) — eles passam a delegar ao service.
